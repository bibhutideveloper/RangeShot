Section 2 • Multi-card Grid (Y: ~850px - 1800px)

Component Architecture Validation

Each card below tests horizontal layout fidelity across stitched seams. Check that texts and borders remain perfectly aligned without split text or vertical compression.

1. Shadow DOM Isolation

RangeShot injects UI into an open Shadow DOM root on <rangeshot-host> so host page CSS resets never compromise extension elements.

2. Document Coordinate Tracking

Document coordinates are computed as documentY = window.scrollY + clientY, surviving normal scrolling and window resizes.

3. Slicing & DPR Math

Canvas coordinates accurately multiply document dimensions by window.devicePixelRatio, ensuring crisp output at 100%, 125%, 150%, and 200% zoom.

4. Local-First Processing

Zero telemetry. Zero external servers. All canvas operations execute in-memory inside the browser sandbox.
